## 📌 Sobre

Este repositório reúne projetos, exercícios e estudos desenvolvidos
durante meu aprendizado de Banco de Dados e SQL.

Os projetos utilizam diferentes cenários para praticar conceitos
de criação, estruturação e manipulação de bancos de dados relacionais.
